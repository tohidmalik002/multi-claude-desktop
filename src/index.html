    Profiles

    Where should profiles be stored?

    Each profile is a folder holding one Claude account's sign-in, local sessions and MCP settings. Pick a folder used only for profiles.

    If the folder you choose already holds other files, a claude-accounts folder is created inside it. You can change this later.
